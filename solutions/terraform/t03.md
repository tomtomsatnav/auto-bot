# T03 solution: Modules

## Bug 1: wrong module source path (`init` fails)
```
Error: Unreadable module directory
Unable to evaluate directory symlink: lstat module: no such file or directory
```
**Fix:** `source = "./modules/service-config"`

## Bug 2: required variable not passed
The `port` variable has no default, so it's required:
```
Error: Missing required argument
The argument "port" is required, but no definition was found.
```
**Fix:** add `port = 9000` to `module "worker_config"`.

## Bug 3: output name mismatch
The module defines `config_path`, not `file_path`. **Fix:** `module.api_config.config_path`

## Bug 4: files written inside the module folder
`path.module` is the **module's own folder**, so files land in `modules/service-config/output/`. **Fix:** use `path.root`, the root folder you ran Terraform from:
```hcl
filename = "${path.root}/output/${var.service_name}.json"
```

## Say this in the interview
- "A module's variables are its inputs and its outputs are the only things callers can see. Anything else inside is private."
- "Whenever the source path changes, I need to rerun `terraform init`, because that's what fetches modules."
