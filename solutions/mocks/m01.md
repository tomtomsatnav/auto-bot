# M01 solution: Orders service on ECS

## Dockerfile

| # | Issue | Type |
|---|---|---|
| 1 | `requirement.txt` typo: the build fails | Build |
| 2 | `COPY . .` before `pip install`: every code change reinstalls everything | Review |
| 3 | No `.dockerignore`: `COPY . .` also copies `infra/`, including `.terraform/` (hundreds of MB of provider binaries) and **`terraform.tfstate`, which can contain secrets**, into the image | Review / **security** |
| 4 | Runs as root | Review / security |

**Fixed Dockerfile:**
```dockerfile
FROM python:3.12-slim

ENV PYTHONUNBUFFERED=1

RUN useradd --create-home --uid 10001 appuser

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY app/ ./app/

USER appuser

EXPOSE 8000
CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "8000"]
```
Copying only `app/` fixes the leak at the source; add a `.dockerignore` as well (`.git`, `infra/`, `.terraform`, `*.tfstate*`, `.env`).

## Terraform

| # | Issue | Caught by |
|---|---|---|
| 5 | `container_definitions` must be a **list** of containers: `jsonencode([{ ... }])`, not `jsonencode({ ... })` | apply (validation is skipped at plan because the image URL isn't known yet) |
| 6 | `network_mode = "bridge"`: **Fargate requires `"awsvpc"`** | apply |
| 7 | `containerPort = 8080`, but the app listens on **8000** | runtime (tasks fail health checks or can't be reached) |
| 8 | Security group allows port **80**, but the container listens on **8000** | runtime |
| 9 | Log group is hardcoded to `"/ecs/orders"`, but the resource creates `"/ecs/orders-api"`, so tasks fail to start because the log group doesn't exist | runtime |
| 10 | `:latest` with `MUTABLE` tags: you can't tell what's deployed, and rollbacks are unreliable. Use immutable tags (git SHA) | Review |

**Key Terraform fixes:**
```hcl
resource "aws_ecs_task_definition" "app" {
  family                   = var.name
  requires_compatibilities = ["FARGATE"]
  network_mode             = "awsvpc"
  cpu                      = 256
  memory                   = 512
  execution_role_arn       = var.execution_role_arn

  container_definitions = jsonencode([
    {
      name      = var.name
      image     = "${aws_ecr_repository.app.repository_url}:${var.image_tag}"
      essential = true

      environment = [
        { name = "APP_ENV", value = "production" }
      ]

      portMappings = [
        { containerPort = 8000, protocol = "tcp" }
      ]

      logConfiguration = {
        logDriver = "awslogs"
        options = {
          "awslogs-group"         = aws_cloudwatch_log_group.app.name
          "awslogs-region"        = var.region
          "awslogs-stream-prefix" = "app"
        }
      }
    }
  ])
}
```
Plus a `variable "image_tag" { type = string }`, `image_tag_mutability = "IMMUTABLE"`, and the security group ingress changed to 8000.

**The theme:** issues 7, 8 and 9 are only visible by **comparing files against each other**. That's the skill this mock is testing, and it's what real platform work looks like.
